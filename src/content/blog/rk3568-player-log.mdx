第一次看到视频在屏幕上播放时，确实开心了几分钟。

然后很快发现：暂停之后图标没变，拖动进度条会弹回去，U盘拔掉后列表还留着旧文件。播放器真正“能用”，和“有画面”，中间隔着很多小问题。

## 目前完成的部分

| 部分 | 现在的状态 |
| --- | --- |
| 本地音视频播放 | 常见格式可以正常播放 |
| U盘读取 | 插入后自动刷新文件列表 |
| 触摸操作 | 按钮和滑块已适配 |
| 音量控制 | 可以调节并保持当前状态 |
| 播放进度 | 支持显示、拖动与跳转 |

## 进度条为什么会打架

播放器会不断回报当前时间，手指拖动时界面也在改变滑块位置。如果两边同时更新，滑块就会来回跳。

最后把逻辑拆成了两个状态：

1. 正常播放时，滑块跟随播放器进度。
2. 开始拖动后，暂时忽略播放器回报。
3. 松手时提交一次跳转，再恢复正常更新。

看起来只是一个很小的细节，但修好以后整个播放器突然“像个播放器了”。

## 关于界面

> 技术藏在后面，使用感受留在前面。
