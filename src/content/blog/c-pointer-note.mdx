指针刚开始学的时候像一道雾，`*` 和 `&` 看久了甚至会觉得它们只是两种不同的装饰符号。

最近重新写嵌入式代码，又碰到几个容易弄混的地方，于是随手记下来。不是教程，更像是给未来自己的提醒。

## 先问“它存的是什么”

看到一个变量时，我现在会先用一句话说清它：

```c
int value = 42;
int *pointer = &value;
```

- `value` 存的是整数 `42`
- `pointer` 存的是 `value` 的地址
- `*pointer` 表示沿着这个地址找到那里的整数

这样说虽然很慢，但比盯着符号猜要可靠。

## 数组和指针很像，但不是一回事

在很多表达式里，数组名会转换成指向首元素的指针，所以它们用起来很像。但数组本身仍然有固定的整体大小。

```c
int values[4] = {1, 2, 3, 4};
int *p = values;

printf("%zu\n", sizeof(values)); // 整个数组的大小
printf("%zu\n", sizeof(p));      // 一个指针的大小
```

| 写法 | 我会怎么理解 |
| --- | --- |
| `values[2]` | 取数组第三个元素 |
| `*(values + 2)` | 移动两个元素后取值 |
| `&values[2]` | 第三个元素的地址 |

## 传指针前多做一次检查

```c
bool update_value(int *target, int next) {
    if (target == NULL) {
        return false;
    }
    *target = next;
    return true;
}
```

> 能在函数入口处理的无效输入，就不要等它变成一次难找的崩溃。

## 暂时的结论

指针不是靠背语法突然学会的。多画几次内存关系，多写几个小例子，雾会慢慢散一点。
